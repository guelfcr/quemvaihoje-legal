## Por que um repositório separado

O código-fonte do aplicativo vive em `quemvaihoje-app` (privado). Os documentos
legais precisam ser **públicos** (Play Store, LGPD, requisição de qualquer
titular), então ficam isolados aqui. GitHub Pages no plano free só serve repos
públicos — separar permite publicação gratuita sem expor o código do app.

## Como editar

1. Faça as alterações em `privacy.html` ou `terms.html`.
2. **Atualize a versão e a data** no topo do arquivo editado (linha
   `Versão X.Y · Vigente desde DD de mês de AAAA`).
3. Commit + push para `main`.
4. GitHub Pages refaz o deploy em ~1 minuto.

Mudanças materiais (novos dados coletados, novos sub-processadores) também
devem ser comunicadas dentro do aplicativo antes da entrada em vigor — veja
seção 10 da Política de Privacidade.
